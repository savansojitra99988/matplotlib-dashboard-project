# 🎨 Matplotlib Dashboard Project

> *“Data is not just numbers — it’s a story waiting to be told.”*  
This project is my attempt to turn raw CSV files into a **visual narrative** using Python’s most powerful plotting library: **Matplotlib**.

---

## 🚀 Why This Project?
I built this dashboard as part of my learning journey in data visualization.  
It’s designed to be **internship‑ready**: clean code, clear insights, and creative presentation.  
Think of it as a **mini data‑storytelling portfolio** — showing that I can take datasets and transform them into meaningful visuals.

---

## 📊 Features
This dashboard combines **four different visualization styles** into one cohesive figure:

1. **👨‍💻 Developer Salary Trends**  
   - Line plots with shaded regions.  
   - Shows how Python and JavaScript salaries compare to all developers.  
   - Highlights where Python developers earn more or less than the average.

2. **📺 YouTube Scatter Plot**  
   - Interactive scatter plot of views vs likes.  
   - Colored by like/dislike ratio.  
   - Log‑scaled axes to handle viral vs small videos.  
   - Hover tooltips with `mplcursors` for interactivity.

3. **📈 Histogram of Ages**  
   - Distribution of developer ages.  
   - Red dashed line marks the mean age.  
   - Quick way to see the spread of experience.

4. **🥧 Pie Chart of Language Usage**  
   - Exploded slice for Python (because it deserves the spotlight).  
   - Shadow effect for depth.  
   - Shows language popularity in a fun, engaging way.
